# Drift detection benchmark: final 20-seed experiment

This folder contains the final train-validation-test benchmark notebook and
the result artifacts produced by its completed 20-seed run.

## Contents

- `drift_benchmark_v6_train_validation_test_20seeds.ipynb` — the final
  benchmark implementation.
- `results/aggregate/` — pooled result tables and figures generated by the
  notebook.
- `results/per_seed/seed42/` through `seed61/` — the two reportable CSV files
  from each independent seed:
  - `results.csv`: occurrence-level drift-detection results.
  - `arl0_null.csv`: held-out drift-free false-alarm verification.

The included result files are the outputs needed to inspect the reported
metrics and reproduce the aggregate analyses without rerunning the expensive
feature-extraction and calibration stages.

## Experimental configuration

The full run uses:

- CIFAR-10 with class 0 as the in-control distribution.
- Twenty seeds, 42 through 61.
- A per-seed 50%/25%/25% identity-disjoint train-validation-test split of the
  6,000 class-0 images.
- A frozen ImageNet-pretrained ResNet-18 feature extractor.
- Sliding windows of 50 observations with stride 1.
- Twenty retained principal components per feature block.
- Threshold calibration on 555,000 validation observations, producing
  554,951 overlapping scores.
- A nominal average inter-event time (AIET) target of 370 window equivalents,
  or 18,500 incoming observations, with a 50-step alarm-event cooldown.
- Dedicated held-out drift-free streams for realized AIET verification.

The notebook evaluates a broader set of raw conditions and methods than the
final manuscript reports. In particular, the files retain recurring-drift
conditions and the legacy CUSUM variants for auditability. The thesis reporting
subset excludes recurring-drift results and excludes CUSUM/CUSUM-R because
their held-out false-alarm rates were not adequately matched.

## Running the notebook

Create a Python environment and install the packages in `requirements.txt`,
then open the notebook from this directory. CIFAR-10 is downloaded
automatically into `data/`.

The default full run takes several hours. A smoke test can be run by setting
`DRIFT_QUICK=1` before starting the notebook kernel. The notebook writes a new
`runs_v6_train_validation_test_20seeds/` directory when run with its default
configuration.

The notebook can reuse compatible training-fitted artifacts from a neighboring
`runs_v6/` directory when available. That cache is optional: without it, the
notebook recomputes the required artifacts. Previously generated thresholds
and test results are not reused from `runs_v6/`.

## Excluded caches

To keep this repository suitable for ordinary GitHub hosting, the release does
not include generated VAE checkpoints (`*.pt`), per-seed serialized calibration
state (`seed_state.pkl`), or raw alarm-index caches (`alarm_indices.npz`).
These files total more than 300 MB and are reproducible by running the
notebook. They are computational caches rather than the tabular or graphical
results used in the thesis.
